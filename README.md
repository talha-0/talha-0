## What I'm working on

- **Multi-object tracking at ViewScan** (C++, Python, Slurm, CUDA). Shipped an optical-flow identity relinker in the production tracker: 48% fewer ID switches, 50% fewer duplicate identities, and +3 HOTA across 58 videos with no regressed videos.
- **Bookend** at Hofstra: an automated pipeline for long-format AI video generation that cut drift from roughly 400% to 20–30% across iterations.
- **Eye-tracking analysis** at Hofstra: extracting fixations and saccades from gaze data in Python with a method grounded in published research.
